## kantor.live (Польша, основной)

**HTML `/kantory/warszawa`.** Найдено 80 kantorów, по 25 на странице, всего 4 страницы. Ссылки `?page=2..4` есть в разметке, последняя страница видна из пагинации.
- В каждой строке есть название, адрес (`Chmielna, 2`), полное расписание на неделю (модальное окно `Godziny pracy`) и до трёх валют. Курсы двух видов: розничные и оптовые («Kurs hurtowy»). У USD бывает отдельная строка «USD (Nowy)» для купюр нового образца.
- Колонка `time-updated` пустая у всех 25 строк. **Времени курса в HTML нет.**
- Координат в HTML нет, в JSON-LD тоже.

**Режим «Na mapie».** Он берёт данные из внутреннего JSON `GET /api/v1/kantors?city=warszawa&per_page=1000&locale=pl`. Адрес нашёлся в `js/map.*.js`. Один запрос возвращает весь город.
- Поля: `id`, `slug`, `name`, `address` (полный, с индексом), `lat`, `lon`, `schedule` (по дням `mo..su`, `begin`/`end`), `phones`, `site`, `rates.retail` / `rates.wholesale`, `updated_at` (время изменения карточки, а не курса).
- Курс: `{currency, base_currency: "PLN", amount: 1, buy, sell, updated_at}`. **Время обновления есть у каждой валюты.**
- **Координаты есть у 51 из 80.** У остальных `lat`/`lon` пустые.
- Выходной закодирован как `00:01–00:02`. Круглосуточная работа — `00:00–23:59`.

⚠️ **Находки:**
1. **Свежие курсы есть только у 15 из 80 kantorów.** У них в JSON заполнено `rates.retail`, и все курсы сегодняшние. С курсом USD и координатами одновременно — 11. Остальные 65 приходят с пустым `retail`. В HTML у части из них курсы показаны, но, судя по значениям, они старые. Например, у Kantor Dukat EUR 4,26/4,29 при рыночном 4,37/4,38, и даты у этих курсов нет.
2. **`updated_at` курса помечен `+00:00`, но на деле это время по Варшаве.** В 14:02 UTC пришли курсы с `16:00:18+00:00`. Адаптер должен трактовать это время как Europe/Warsaw.
3. Иногда заполнена только одна сторона курса, например у BGN `sell: "0"`. Правило «0 = валюты нет» нужно применять к каждой стороне отдельно, а не к валюте целиком.

## myfin.by (Беларусь, основной)

**Список `/bank/belarusbank/currency`.** Это страница одного банка. Всего в Минске 21 банк (список `data-alias`), то есть на город нужен 21 запрос.
- 135 отделений Беларусбанка, все в одном HTML без пагинации.

- Внимание: атрибут `data-currency-rates-sell="usd"` содержит **курс покупки банка**: 3,035, у API Беларусбанка `USD_in` = 3,035. Подписи у myfin даны с точки зрения клиента.

**Страница отделения** `/bank/belarusbank/department/232-...`:

- Карта подгружает точки из `/ajax-map/map-json?mapObjectId=232&type=map`. Отдаёт ли этот адрес сразу все отделения банка, пока не проверял.

## API Беларусбанка (официальный)

`GET https://belarusbank.by/api/kursExchange?city=Минск` возвращает JSON-массив из 137 отделений.
- Поля: `filial_id`, `sap_id`, `filials_text` («Отделение №510/174»), адрес по частям (`name_type`, `name`, `street_type`, `street`, `home_number`), `info_worktime`, `kurs_date_time`, курсы `XXX_in` (банк покупает) и `XXX_out` (банк продаёт), кросс-курсы `USD_EUR_in` и др.
- Часы работы в едином формате `|Пн 10 00 19 00    |…|Сб      |Вс      |`. Все 137 строк разбираются одним регулярным выражением. Выходной — пустое значение.
- `kurs_date_time` одно на весь город (`2026-10-07 17:20:00`), без пояса, то есть время по Минску.
- Валюты: USD, EUR, RUB, CNY почти везде; PLN в 32 отделениях, CHF в 16, SEK в 11, CZK в 5, CAD в 4, JPY в 2. Значение `0.0000` означает, что валюты нет.
- ❌ **Координат нет.**
- ⚠️ **Курсы даны за разное количество единиц, и в ответе это не указано.** RUB 3,15 — за 100; CZK 13,0 — за 100; JPY — за 100; PLN 7,3 — за 10; SEK — за 10; CNY 4,53 — за 10; USD, EUR, CHF, CAD — за 1. Нужна зашитая таблица масштабов. Она совпадает с масштабами Нацбанка РБ, но её надо сверять.

- Из PDF: `GET https://developer.sber-bank.by/api/rates/v1/currencyExchange?exchangeType=Cash`. Параметры: `idBranch`, `sourceCurrency`, `targetCurrency`, `direction`. В ответе: `idBranch`, `unitCurrency`, `exchangeRate`, `dateTime`, `updateDataTime`.

## Ответы на открытые вопросы спецификации

- **Есть ли координаты в данных карты kantor.live?** Да, в JSON `/api/v1/kantors`, но у 51 из 80. Остальным нужны OSM или Nominatim.
- **Отдаёт ли myfin.by координаты отделений?** В списке нет. На странице каждого отделения есть (центр карты), но это один запрос на отделение.
- **Где время обновления курса?** У kantor.live — `rates.retail.*.updated_at` в JSON карты (время по Варшаве, хотя помечено как UTC); в HTML времени нет. У myfin.by времени курса по отделению нет совсем. У rates.fm — `lastUpdatedAt` провайдера. У Беларусбанка — `kurs_date_time`.
- **Пагинация.** kantor.live: HTML `?page=N` по 25, JSON отдаёт весь город одним запросом. rates.fm: 15 на страницу, в JSON есть `lastPage`. myfin.by: пагинации нет, одна страница на банк и город.
- **Блокируют ли запросы с Cloudflare?** С локальной машины всё отвечает 200 с честным User-Agent. С серверов Cloudflare проверим на шаге 2, когда будет развёрнут воркер.

## Расхождения со спецификацией — нужны решения

### 1. kantor.live: HTML или JSON карты
Спецификация предполагает разбор HTML, но время курса и координаты есть только во внутреннем JSON карты. Этот адрес не документирован и может измениться.
- **A (рекомендую).** Основной путь — JSON `/api/v1/kantors` (1 запрос на город вместо 4). HTML не используем.
- **B.** Основной путь — JSON, а при ошибке берём из HTML список с часами работы, но без курсов.
- **C.** Как в спецификации, только HTML: координаты из OSM/Nominatim, время курса заменяем временем сбора. Минус: устаревшие курсы будут выглядеть свежими.

### 2. kantor.live: свежий курс только у 15 из 80 kantorów в Варшаве
Проверка шага 3 («у большинства есть координаты и курс USD») в нынешнем виде не пройдёт.
- **A (рекомендую).** Показываем только курсы с датой. Kantory без свежих курсов попадают в базу, но плашки у них нет (FR-15). Проверку шага 3 меняем на «80 kantorów в базе, у тех, кто публикует курс, он есть и с координатами».
- **B.** Дополнительно берём из HTML курсы без даты и показываем с пометкой «дата курса неизвестна». В выборе лучшего они не участвуют, как в FR-24.
- **C.** Добавить ещё один польский источник курсов. Его нужно сначала найти и проверить.

### 3. myfin.by: нет координат, часов и времени курса в списке
- **A.** Координаты и часы берём со страниц отделений раз в неделю, курсы — со списков раз в 15 минут, время курса = время сбора. Минус: это сотни запросов в неделю на город. На бесплатном тарифе Workers есть лимит подзапросов на один запуск, поэтому сбор придётся растянуть на много запусков cron. Лимит уточним на шаге 2.
- **B (рекомендую сначала проверить).** Одним запросом посмотреть, отдаёт ли `/ajax-map/map-json` сразу все отделения банка с координатами. Если да, это 1 запрос на банк и город вместо сотен.
- **C.** Координаты брать из OSM/Nominatim по адресу. Часы считать неизвестными (FR-22: обменник «открыт», в карточке «часы работы не указаны»), а флаг «работает сейчас» из списка использовать только как подсказку.

### 4. API Сбера недоступен
- **A (рекомендую).** Курсы Сбера берём с myfin.by (`/bank/bps-sberbank/currency`), как у остальных банков. Официальный API убираем из MVP.
- **B.** Написать на api@bps-sberbank.by и спросить актуальный адрес. Это письмо от вашего имени, отправляете вы сами.
- **C.** Поискать актуальный адрес API на sber-bank.by: несколько запросов, результат не гарантирован.

### 5. rates.fm почти не даёт стационарных kantorów
Около 6 брендов без отделений и адресов. Остальное — банки и онлайн-kantory, которых в MVP нет. Решение можно отложить до шага 11.
- **A (рекомендую).** Отложить и решить на шаге 11. Возможно, используем только для проверки, что курсы kantor.live правдоподобны.
- **B.** Сопоставлять бренды rates.fm с kantorami kantor.live по названию: курс бренда применяем ко всем его точкам.
- **C.** Убрать rates.fm из MVP.

### 6. Мелочи, которые учту в адаптерах без отдельного решения
- Масштабы курсов Беларусбанка зашиваю таблицей: RUB, CZK, JPY за 100; PLN, SEK, CNY за 10.
- Правило нулевого курса применяю к каждой стороне отдельно.
- Время из источников без пояса или с неверным поясом трактую как местное время страны.
- У kantor.live выходной закодирован как `00:01–00:02` → `null`.
- У Беларусбанка `kurs_date_time` вчерашний (17:20), а курсы при этом действуют. В выходные курс банка может быть старше 24 часов, хотя остаётся актуальным, и FR-24 пометит его как устаревший. Предлагаю вернуться к этому на шаге 7.
