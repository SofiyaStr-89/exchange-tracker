# Карта обменников — правила работы

Главный источник требований — [SPEC.md](SPEC.md). Прочитать целиком в начале каждой сессии. Ссылаться на требования по номерам FR-N.

## Как работаем

- Идём строго по разделу SPEC.md «План разработки по шагам», по одному шагу за раз.
- В конце шага — остановка: что сделано + как выполнить «Проверку» шага (что открыть, куда нажать, что должно быть видно). Следующий шаг — только после слова «дальше».
- Если спецификация расходится с реальностью (нет поля у источника и т.п.) — не придумывать обход молча: описать проблему и предложить 2–3 варианта.
- Только бесплатные сервисы и библиотеки. Если что-то требует оплаты или привязки карты — сначала спросить.
- Аккаунты (Cloudflare, GitHub) пользователь создаёт сам. Когда нужен вход — назвать команду (например, `npx wrangler login`) и ждать.
- Все тексты интерфейса — на русском, в отдельном файле локализации (позже добавится польский).
- Коммит после каждого шага; в сообщении — номер шага и FR, например `Шаг 3: адаптер kantor.live (FR-14, FR-21)`.
- Внешние сайты-источники не трогать чаще, чем нужно: пауза ≥ 1 с между запросами, честный User-Agent, не чаще раза в 15 мин на город; API Сбера — не больше 2 запросов в минуту.

## Ключевые решения из спецификации

- PWA (Vite + TypeScript, Leaflet + leaflet.markercluster) на Cloudflare Pages → `app/`.
- Бэкенд: Cloudflare Worker + Cron Triggers + D1 → `worker/`. Телефон никогда не ходит к источникам курсов напрямую.
- Таблицы D1: `exchangers`, `rates`, `city_fetches`. API: `/api/exchangers?lat&lng&radius`, `/api/exchangers/:id`, `/api/currencies?country`, `/api/health`.
- Источники: PL — kantor.live (основной), rates.fm (доп.); BY — myfin.by (основной), API Беларусбанка и Сбера (приоритетные для своих банков). Координаты: источник → OSM Overpass → Nominatim (кэш навсегда). Каждый источник — отдельный адаптер к общей модели.
- В Польше только kantory, без отделений банков.
- Курсы хранятся как «местная валюта за 1 единицу иностранной»; 0/пусто = валюты нет.
- «Покупаю» = курс продажи обменника (sell), «Продаю» = курс покупки (buy) (FR-12).
- Открыт/закрыт — по местному времени страны (Europe/Warsaw, Europe/Minsk), не телефона (FR-21).
- Карта: тайлы OSM, поиск Photon (запасной Nominatim).
- На телефоне всё в localStorage, каждое обращение в try/catch.
- Приватность: координаты пользователя не сохраняются и не логируются; без аналитики.
